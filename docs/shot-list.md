# רשימת צילום — שני הסלוטים החסרים בגלריה

**למה זה קיים:** הגלריה באתר בנויה על 24 סלוטים. עשרים ושניים מהם נושאים
פריימים אמיתיים של הסטודיו מאז 11.8.2026. **שניים עדיין מציגים נגזרות ישנות
מתקופת האינסטגרם**, ולא בגלל תקלה — בגלל שהספרייה שקיימת פשוט לא מכילה את
הפריים הנכון. הם צריכים צילום, לא עריכה.

`tools/build-assets.mjs` בנוי כך שסלוט בלי מקור **נשמר ולא נמחק**, ולכן שני
אלה יכולים לחכות כמה שצריך. אבל הם שני החורים היחידים שנשארו.

## g08 — חופה בשקיעה

| | |
| --- | --- |
| **יחס גובה-רוחב** | **21:9** — פריים רחב מאוד, לרוחב |
| **רזולוציה** | 2400px לרוחב לפחות |
| **קטגוריה בגלריה** | `weddings` |
| **טקסט חלופי באתר** | "חופה בשקיעה" |

**למה הוא עוד לא קיים:** שתי החתונות שבספרייה היו עם טקס בלילה, והפריימים
הרחבים היחידים מהטקס כוללים מנחה עם מיקרופון או איש צוות בקאדר.

**מה צריך לתפוס:**
- טקס **באור יום נמוך או בשקיעה** — זה כל העניין של הסלוט
- פריים **רחב מאוד**, שמראה את החופה בתוך הנוף ולא רק את הזוג
- **בלי מנחה, בלי מיקרופון ובלי אנשי צוות** בקאדר
- לצלם לרוחב, ולהשאיר מרווח בצדדים — הפריים ייחתך ל-21:9

## איך מעלים אותם כשיש

הנתיב שעבד ב-11.8 ל-24 פריימים, בלי שינוי:

1. **שם הקובץ הוא מזהה הסלוט.** `g08.jpg` הוא סלוט g08. לא שם המצלמה.
2. להעלות ל-`incoming/` **בענף זמני** דרך ה-UI של GitHub
   (`Add file` → `Upload files`). לא לשורש הריפו.
3. להריץ:

   ```bash
   npm install --no-save playwright-core pngjs sharp   # פקודה אחת
   node tools/build-assets.mjs
   python3 tools/gen-image-schema.py
   python3 tools/gen-sitemap.py
   tools/check.sh && node tools/verify.mjs
   ```

**שתי תופעות לוואי שצפות רק בשלב הזה**, ושתיהן קרו כבר פעם:
- סלוט שהמקור החדש שלו גדול מספיק **מרוויח רוחב מועמד חדש** שהמארקאפ עדיין
  לא מפנה אליו (‏`g17` עבר מ-600 בלבד ל-600+1100).
- **ספירה קשיחה ב-`verify.mjs` זזה** אם תמונה מחליפה קטגוריה.

`g08` ו-`g10` הם גם שני הסלוטים היחידים ללא AVIF, מאותה סיבה בדיוק — אין ממה
לקודד. ברגע שיהיה מקור, הם יקבלו אותו כמו כל השאר.
