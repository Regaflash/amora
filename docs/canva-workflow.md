# Canva — ה-Workflow השבועי לתוכן אינסטגרם

מסמך תפעולי. ההקשר המלא (קישורים לעיצובים הקיימים, שפת המותג, כללי התוכן)
נמצא ב-`docs/canva-brand.md` — לקרוא אותו לפני כל ריצה.

## מה ה-Workflow מייצר

בכל ריצה: **פוסט אחד (1080×1350) + סטורי אחד (1080×1920)**, בעברית RTL,
בשפת המותג, עם תמונה אמיתית של הסטודיו, מתויקים בתיקיית
[Amora Studio](https://www.canva.com/folder/FAHRU0u5qB0) בחשבון ה-Canva Pro.

## בנק המסרים — לרוץ עליו ברוטציה

כל מסר מגובה באתר. אין להמציא מסר חדש בלי שהוא קיים באתר קודם.

| 3 | צילום + וידאו תחת קורת גג אחת | צוות אחד, שפה אחת, בלי תיאומים בין ספקים |

בחירת מסר: לפתוח את התיקייה (`list-folder-items`), לראות אילו מסרים כבר
קיבלו עיצוב לאחרונה, ולקחת את הבא בתור שלא טופל.

## שלבי הריצה (הסדר שעבד, עם המוקשים שכבר נדרכו)

1. **נכסים** — התמונות כבר ב-Canva (ראו מזהים ב-`docs/canva-brand.md`).
   תמונה חדשה מעלים רק מ-URL ציבורי של האתר:
   `https://www.amora-studios.com/assets/img/<file>.jpg`.
2. **יצירה** — `generate-design` עם query מפורט: המסר בעברית, הפלטה
   (שמפניה `#C9AE8C`, שנהב `#FFFDF9`, פחם `#1C1A18`), "warm-minimal,
   luxurious, understated", ו-`asset_ids` של תמונה אחת.
3. **מועמד → עיצוב** — `create-design-from-candidate` על המועמד הראשון.
   המועמדים כמעט תמיד דורשים תיקון — זה צפוי, לא כישלון.
4. **נרמול** (`read-design` עם `open_transaction` ואז `edit-design`):
   - להחליף רקע סטוק בתמונת הסטודיו (`update_fill` על הרקע/RECT).
   - שכבת פחם `#1C1A18` בשקיפות 38–55% מעל תמונות בהירות, טקסטים מעליה
     (`layer_element front`).
   - כותרת שנהב, שורת משנה שמפניה, קו שמפניה 120×3, פוטר
     `Amora Studio · amora-studios.com` — הכול ברוחב 900, left 90, ממורכז.
5. **בדיקת RTL על ה-thumbnail** — שני הבאגים המוכרים:
   - נקודה בסוף כותרת קופצת שמאלה → להוסיף `U+200F` (RLM) אחרי הנקודה.
   - טווח ספרות "3–5" מתהפך → לכתוב "3 עד 5".
   - פונט שמעוות עברית (מראה/צורות שבורות) → למחוק את הטקסט ולהוסיף
     `add_text` חדש (הפונט הדיפולטי תקין).
6. **שמירה ותיוק** — `finalize: commit`, שם בתבנית
   `Amora IG פוסט NN — <מסר>`, ואז `move-item-to-folder` לתיקייה
   `FAHRU0u5qB0`.
